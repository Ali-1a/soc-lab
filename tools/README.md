# Tools

Small, self-contained tools I built while training. Larger tools live in their own repositories:

- **[IOC Triage](https://github.com/Ali-1a/ioc-triage)** — extract, defang, de-duplicate and rank indicators of compromise by the Pyramid of Pain. Browser page + Python CLI, tested on real CISA IOC data. *(moved to its own repo)*

In this folder:

- **[SOC Alert Report Builder](soc-report-builder.html)** — a single-page form that turns triage findings into a structured incident report (5W summary, defanged IOCs, recommended next steps). Download the file and open it in a browser.
